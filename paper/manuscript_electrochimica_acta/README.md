# KAIRIS manuscript — Electrochimica Acta

This folder is a local LaTeX project using Elsevier CAS single-column template
version 2.4. The untouched source template and its manifest are retained beside
the working manuscript for provenance.

Compile `main.tex` with PDFLaTeX and BibTeX. Keep all submission files at this
same directory level: Elsevier Editorial Manager does not accept LaTeX source
files arranged in subfolders.

Before submission:

1. recheck the current journal Guide for Authors;
2. replace every pending author, affiliation and declaration field;
3. add only verified references;
4. generate all result tables and figures from the frozen analysis;
5. remove drafting comments and confirm that the submitted PDF matches source;
6. include the required AI-use disclosure, if applicable.

Official instructions:
<https://www.elsevier.com/en-gb/researcher/author/policies-and-guidelines/latex-instructions>
